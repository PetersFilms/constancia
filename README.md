# Constância

Aplicativo pessoal de acompanhamento de hábitos e evolução corporal, publicado como site estático no GitHub Pages.

## Privacidade e armazenamento

O aplicativo não possui conta nem banco de dados. Hábitos, marcações, avaliações e pesagens ficam no armazenamento local do navegador. Cada navegador e aparelho mantém dados separados.

Use **Backup** para exportar uma cópia dos registros e **Restaurar** para levá-los a outro navegador ou recuperá-los. Não adicione arquivos de backup ao repositório.

## Publicação

O site pode ser publicado diretamente pelo GitHub Pages a partir da branch `main` e da pasta raiz. Não há etapa de compilação.
